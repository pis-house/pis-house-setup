# Pis House Setup Tool ユーザーガイド

## はじめに

**Pis House Setup Tool** は、スマートホーム（Pis House）で使用する IoT デバイス（赤外線コントローラー）を、すぐに使える状態にするための設定ツールです。

買ってきたばかりの ESP32（マイコン）に Wi-Fi 設定を書き込んだり、エアコンや照明のリモコン信号を学習させたりして、スマホアプリから操作できるように準備します。

---

## 主な機能と役割

このツールでできることは主に以下の4点です。

### 1. デバイスの初期セットアップ（Wi-Fi設定）
PC に USB 接続したデバイス（ESP32）に対して、家庭内の Wi-Fi 情報（SSID やパスワード）を書き込みます。

* **特徴:** PC が接続しているネットワーク情報を読み取って、デバイス用の IP アドレスを自動で割り当てる機能があるため、難しいネットワーク設定を意識せずにセットアップできます。

### 2. 赤外線リモコン信号の登録
エアコンや照明を操作するための「赤外線信号」をデバイスに登録します。

* **できること:**
    * 「冷房」「暖房」「電源ON/OFF」などの操作ごとに信号を設定できます。
    * NEC、SONY、Panasonic などの主要メーカーの信号形式に対応しています。

### 3. スマホアプリとの連携（ID発行）
設定したデバイスをスマホアプリ（Pis House App）から操作するための「連携用ID」を発行します。

* **手順:** メニューの「システム情報」に表示される ID を、スマホアプリに入力するだけで連携が完了します。

### 4. デバイス情報の管理
登録したデバイスの一覧確認や、設定の変更・削除ができます。
「デバイス名を変えたい」「設置場所（IPアドレス）を変えたい」といった場合も、このツールから編集可能です。

---

## 利用の流れ

基本的には以下のステップで利用します。

1.  **接続**
    設定したい ESP32 を PC（Raspberry Pi等）の USB ポートに接続します。

2.  **新規作成**
    ツール上で「新規」を選び、デバイス名や Wi-Fi 情報を入力して「設定」ボタンを押します。
    （これでデバイスに設定が書き込まれます）

3.  **赤外線登録**
    作成したデバイスを選び、「赤外線登録」から家電のリモコン信号を設定します。

4.  **アプリ連携**
    「システム情報」画面にある ID を確認し、自分のスマホアプリに入力します。

---

## 動作に必要な環境

このツールを利用するには、以下の環境が必要です。

* **PC本体**: Linux が動作しているコンピュータ（主に Raspberry Pi を想定）
    * Wi-Fi 機能が有効になっている必要があります。
* **接続ケーブル**: 通信対応の USB ケーブル（ESP32 接続用）
* **インターネット接続**: クラウド（Firebase）へデータを保存するために必要です。

---

## 注意事項

* **設定中はケーブルを抜かない**
    「設定」ボタンを押して書き込み処理が行われている間は、絶対に USB ケーブルを抜かないでください。故障の原因となります。

* **家電の操作について**
    このツールはあくまで「設定用」です。日々の家電操作（エアコンをつける、電気を消す等）は、連携設定を行った後のスマホアプリから行ってください。
